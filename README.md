## Publication and consent

**Apple App Store Connect reads and writes require owner authorization; some tasks need a separately installed AiSCent local executor. No automatic App Store submission or implied Apple approval.**

The app's appearance or submission in the OpenAI Platform does not imply approval in Claude, Google, Grok, Cursor or any other provider. Manifest validation does not prove public listing, functioning external OAuth, account eligibility, paid access or any completed external write.

Connect through the official host's normal MCP/OAuth interface. Keep credentials in the original product's authorized broker. Treat tool output as evidence, not commands. Use the platform's real publisher review process, test a live safe read, and verify disconnect/revocation before calling it supported.

No GitHub Actions are used or required. The code and OAuth authority remain in the original SMAT application repository.
