# AiSCent

Use only the authorized `aiscent` MCP endpoint, at https://aiscentmcp.com/mcp.

Discover supported AiSCent tools and current app identity first. Ask for Apple/local executor access only when necessary; when missing, report the exact required handoff and continuation ID. Separate evidence from assumptions and never claim App Store submission without verified App Store Connect confirmation.

## Safe starter tasks
- Discover my authorized App Store Connect apps
- Check localization and screenshot readiness for my selected iOS app
- Tell me which Apple access is missing for the next release step.

## Acceptance

Verify tool discovery, normal owner consent and a real read in the target AI host. No output is a license to bypass service permissions. Stop on missing grant, unsupported tool, or stale evidence and explain what is needed next.
